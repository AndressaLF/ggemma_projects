🗺️ batimetria_kml_shape

Objetivo: pegar batimetria em formato tabular ou texto (coordenadas + profundidade) e desenhar no mapa — gerando KML (Google Earth) ou shapefile (QGIS), sem montar o mapa na mão.

Suite de scripts Python (não é um pacote instalável). Versões: suite — SHP v1.8.0 · linhas v1.0.1. Foco exclusivo: arquivo tabular/texto → desenho no mapa.

CSV · TXT · XYZ · Excel · LOG → KML / SHP 🖱️ Scripts .py 🔒 Offline

🎯 Para que serve (objetivo)

Em campanhas marítimas, profundidade e posição costumam chegar em arquivos “chatos” de planilha ou texto. Abrir linha a linha no Excel não mostra a área no mapa. Esta suite resolve exatamente isso:

  • Lê uma pasta com arquivos tabulares/texto de batimetria
  • Identifica (heurísticas) colunas de coordenada e profundidade
  • Limpa pontos inválidos e gera arquivo pronto para visualizar
  • Saída: KML e/ou shapefile na mesma pasta

Em uma frase: dado tabular de batimetria → desenho no mapa.

📥 O que ela aceita (entrada)

Não é só TXT e Excel. A suite trabalha com dados tabulares ou em texto que tenham posição + profundidade:

Tipo Extensões típicas Quando aparece
Planilha .xlsx, .xls Exportações de campo / processamento em Excel
Tabela texto .csv, .txt, .xyz Listas lon/lat/z ou X/Y/z separadas por vírgula, espaço ou tab
Log de campo .log (e afins em texto) Registros de ecosonda / navegação em formato texto

O que o arquivo precisa ter (em colunas, mesmo sem nome perfeito):

  • Coordenadas geográficas (longitude + latitude) ou UTM (X + Y)
  • Profundidade / cota (Z)

Fora do escopo: formatos binários / raster de campo (BAG, LAS, GeoTIFF, GSF, XTF, KMALL e similares). Esta suite trabalha com entrada tabular ou texto.

📤 O que ela entrega (saída)

  • 🌍 Conversor KML converter_batimetria2.py Gera .kml para abrir no Google Earth e conferir se a área “cai” no lugar certo — conversão rápida de visualização.
  • 📐 Contornos + linhas converter_shapefile_batimetria.py · v1.8.0 Gera shapefiles de área (CA_…) e trajeto (L_…) para QGIS / GIS. Separa pedaços longe um do outro no mesmo arquivo.
  • 〰️ Só linhas converter_linhas_batimetria.py · v1.0.1 Exporta apenas linhas de navegação (caminho da embarcação).

📌 Por que isso é necessário

Em campanha, profundidade e posição costumam chegar em planilha ou texto. Abrir linha a linha no Excel não mostra a área no mapa. Esta suite existe para transformar esse arquivo tabular em KML ou shapefile pronto para Google Earth / QGIS — conversão rápida, local e didática.

✨ O que você ganha na prática

🌍 Ver no Google Earth

KML para checar área e profundidades sem montar projeto GIS.

📐 Usar no QGIS

Shapefile de área e/ou linha, pronto para abrir no mapa.

🧹 Limpeza básica

Tenta remover profundidade inválida e pontos fora do esperado.

🖱️ Pasta na janela

Escolhe a pasta com o mouse — não precisa digitar caminho.

👁️ Como fica na prática

Você aponta a pasta com CSV, TXT, XYZ, Excel ou LOG; o script gera KML e/ou shapefile na mesma pasta.

📊 Ilustração do fluxo — nomes de saída seguem o padrão de cada conversor.

▶️ Como começar

cd batimetria_kml_shape
python -m venv .venv
.\.venv\Scripts\Activate.ps1
pip install -r requirements.txt

python converter_batimetria2.py              # KML
python converter_shapefile_batimetria.py     # área + linha
python converter_linhas_batimetria.py        # só linha

Entrada: pasta com CSV, TXT, XYZ, Excel (.xlsx/.xls) ou LOG contendo coordenadas + profundidade. Saída: na mesma pasta que você escolheu.

❓ Em 10 segundos

  • ❓ Só aceita TXT e Excel? → Não. Também CSV, XYZ e LOG (texto/tabular).
  • ❓ Preciso ser programador? → Instalar Python e rodar um dos três scripts.
  • 🔒 Dados sobem para a nuvem? → Não. Tudo local.
  • 🗺️ Substitui o QGIS? → Não. Prepara o arquivo para abrir lá (ou no Google Earth).
  • 🎯 Ponto forte? → Conversor tabular/texto → KML/SHP, com seletor de pasta e saída na mesma pasta.
